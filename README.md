# Gas Sensor IoT Machine Learning Project

## Overview
This project implements a theoretical IoT-based gas monitoring system using machine learning on real-world sensor drift data. The system analyzes gas sensor responses to classify gas types and predict future sensor values.

## Objectives
- Build a deep learning classifier to detect gas types.
- Develop a time-series forecasting model for sensor prediction.
- Design a complete IoT system architecture.
- Visualize insights using Tableau.

## Dataset
Gas Sensor Array Drift Dataset – UCI Machine Learning Repository.

## Machine Learning Models
1. Deep Learning Neural Network for gas classification.
2. Random Forest time-series model for forecasting sensor values.

## Tech Stack
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas / NumPy
- Tableau Public
